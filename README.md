# CAFÉX × Vessel Archive

A static, one-page-at-a-time prospect presentation in the retained Vessel V6-polish visual system. Open index.html or serve this directory. Next/Back, arrow keys and horizontal touch swipe navigate. Evidence buttons open real screenshots with source, date and scope captions. Escape closes evidence.

No service pricing, analytics, forms or external JavaScript. The contact button opens an email draft; it does not send a message. Public-facing content only. Research and QA remain outside this directory.
